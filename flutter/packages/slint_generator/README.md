# slint_generator

Turns `.slint` files into typed Dart wrappers (`*.g.dart`) that run on **any**
Slint backend. Shared by the interpreter (`slint_interpreter`) and the
AOT-compiled path (`slint_compiler`).

```yaml
dev_dependencies:
  slint_generator: ^0.0.1
```

**Full docs:** [slint_generator package page](https://listepo.github.io/slint_dart/packages/slint_generator/), [Getting started](https://listepo.github.io/slint_dart/guides/getting-started/).
