# slint_interpreter

Slint runtime for Flutter via Rust FFI — `slint-interpreter` plus the
software renderer. Provides `SlintInterpreterFactory`, the debug-mode backend
behind the typed wrappers from `slint_generator`.

```yaml
dependencies:
  slint_interpreter: ^0.0.1
```

**Full docs:** [slint_interpreter package page](https://listepo.github.io/slint_dart/packages/slint_interpreter/), [Backends guide](https://listepo.github.io/slint_dart/guides/backends/).
