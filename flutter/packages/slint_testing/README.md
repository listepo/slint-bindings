# slint_testing

Test Slint UIs from Dart through the accessibility tree — no window, no
renderer, no event loop. Runs under plain `dart test` on
`i-slint-backend-testing`.

```yaml
dev_dependencies:
  slint_testing: ^0.0.1
```

**Full docs:** [slint_testing package page](https://listepo.github.io/slint_dart/packages/slint_testing/), [Testing guide](https://listepo.github.io/slint_dart/guides/testing/).
