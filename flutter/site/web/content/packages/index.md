The eight Dart packages. Each page below is the full documentation for that
package — edit the matching file under `site/web/content/packages/`. Package
READMEs in the repo stay short pub.dev overviews that point here.

| Package | Role |
|---|---|
| [slint](/packages/slint) | Backend-agnostic core API and `SlintView` |
| [slint_generator](/packages/slint_generator) | `build_runner` codegen → typed `*.g.dart` wrappers |
| [slint_interpreter](/packages/slint_interpreter) | Debug runtime: software renderer over Rust FFI |
| [slint_compiler](/packages/slint_compiler) | Release/profile AOT: `slint-build` into the app code asset |
| [slint_build](/packages/slint_build) | Shared cargo/native-assets hook plumbing |
| [slint_skia](/packages/slint_skia) | Experimental GPU backend (Skia → Flutter texture) |
| [slint_testing](/packages/slint_testing) | Headless accessibility-tree tests under `dart test` |
| [slint_patrol](/packages/slint_patrol) | Live Patrol finders and gestures over Slint elements |
